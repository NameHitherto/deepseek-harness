# 数据模拟使用评分项数组

[English](guide.md) | 中文

## 变更

本地 `@local/data-simulation` 插件在场景数据中提供字符串数组 `expected`。第 1 版场景库使用单个 `expectedResult` 字符串。下次保存场景库时会写入第 2 版。

## 迁移

1. 重启科研配置档。插件会自动读取已有场景库，更新未编辑的内置场景，并保留已编辑或自定义场景的任务提示词和评分文本。原有评分文本成为一条数组元素。
2. 在**设置 → 内置插件 → 数据模拟**中确认原有场景选择和自定义任务仍在。可编辑场景，将原有评分文本拆成独立条目。
3. 如果代码会读写场景，请使用 `expected`，每条评分标准传入一个字符串。确认消费方能逐项评分。[插件参考](../../../../human-agent/plugins/data-simulation/README.zh.md)
